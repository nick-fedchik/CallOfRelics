# Call of Relics

A Roblox game project.

## Project Structure
- ReplicatedStorage: Shared scripts and modules
- ServerScriptService: Server-side scripts
- StarterPlayer: Player scripts (StarterPlayerScripts, StarterCharacterScripts)
- assets: Game assets (models, images, sounds)

## Setup Instructions
1. Open this folder in Roblox Studio.
2. Place scripts in the appropriate folders.
3. Add assets to the assets folder.
4. Use Roblox Studio to link scripts and assets as needed.

## Getting Started
- This workspace is scaffolded for Roblox game development.
- Customize scripts and assets to build your game.
