## Overview

**Лабіринт** (Labyrinth) — підземна мережа тунелів та печер під поверхнею Біллі Рубін. Вхід через природну карстову воронку. Темна, заплутана локація з елементами стелсу та орієнтування.

**Arcade Type:** Maze / Stealth

## Environment Concept

### Terrain
- Карстова воронка з посадковим майданчиком поруч
- Мережа підземних тунелів (процедурна або фіксована)
- Великі печери з'єднані вузькими проходами

### Structures
- Штучні елементи вбудовані в природні печери
- Двері та шлюзи, що контролюють доступ
- Підземне сховище / архів
- Стародавні ліфти між рівнями

### Atmosphere
- Безпечна, але **темно** — потрібне джерело світла
- Біолюмінесцентні гриби/кристали дають мінімальне освітлення
- Ехо кроків (звуковий дизайн)
- Підземні водойми

## Gameplay — Maze / Stealth

### Arcade Mechanics
- **Навігація:** орієнтування в лабіринті без карти (або з частковою картою)
- **Освітлення:** обмежений ліхтарик, біолюмінесцентні маркери
- **Стелс-елементи:** автоматичні охоронні системи (сенсори, лазерні сітки)
- **Ухилення:** обхід або деактивація пасток
- **Картографування:** відкриття секцій лабіринту додає їх на міні-карту
- **Глухі кути:** тупики з ресурсами або пастками

### Primary Goal
- Дістатися до центру лабіринту — підземного архіву

### Reward
- Найцінніші knowledge items про цивілізацію
- Можливо: карта всіх локацій на планеті
