## Environment

### Terrain
- Зарослий ландшафт з густою рослинністю
- Руїни стародавніх споруд, вкриті мохом та ліанами
- Посадковий майданчик біля входу

### Structures
- Напівзруйновані стіни з символами (аналогічними до Візитки)
- Колони з невідомими написами
- Центральна споруда (archive / бібліотека)
- Пазл-механізми для відкриття прихованих кімнат

### Atmosphere
- Безпечна для дихання
- Підвищена вологість, серпанок від рослин
- Біолюмінесцентні рослини створюють м'яке освітлення

## Gameplay — Puzzle / Archaeology

### Arcade Mechanics
- **Пазли середовища:** переміщення об'єктів, активація механізмів у правильному порядку
- **Дешифрування:** розпізнавання символів, знайдених також у Візитці
- **Археологічний огляд:** сканування стін для виявлення прихованих написів
- **Послідовність відкриття:** кожен розв'язаний пазл відкриває глибшу частину руїн

### Primary Goal
- Знайти knowledge items про цивілізацію та їх зв'язок з будівлею на Візитці

### Optional Objectives
- Дослідити всі кімнати
- Знайти приховані записи
- Зібрати всі символи для декодування

### Resources
- TBD — можливі рідкісні матеріали

### Knowledge Items
- Записи про зниклу цивілізацію
- Перші згадки про "Orbital Silence"
- Можливий компонент для стабілізації сигналу на Візитці

## Signal Connection

Садочок може містити **фрагменти інформації** про сигнал з Візитки:
- Символи на стінах руїн перегукуються з символами на куполі будівлі
- Knowledge items можуть містити інструкцію зі стабілізації сигналу
- Можливо, тут знаходиться компонент, якого бракує на педесталі Візитки
