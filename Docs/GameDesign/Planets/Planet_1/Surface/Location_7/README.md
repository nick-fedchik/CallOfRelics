**Колиска** (Cradle) — біологічний дослідницький комплекс біля великого озера. Оранжерея з екзотичною флорою та фауною під захисним куполом. Локація з елементами виживання та оборони.

## Environment Concept

### Terrain
- Берег великого озера з білірубіново-оранжевою водою
- Густа екзотична рослинність (агресивніша ніж на Візитці)
- Болотисті ділянки, спори в повітрі

### Structures
- Захисний купол (пошкоджений, частково відкритий)
- Оранжерея з рядами вирощуваних рослин
- Лабораторія з зразками флори та фауни
- Система зрошення та фільтрації

### Atmosphere
- Безпечна, але **підвищена концентрація спор** біля озера
- Обмежений час без фільтрації (O₂ drain ×1.5 у споровій зоні)
- Волога, тепла, парникова

## Gameplay — Survival / Defense

### Arcade Mechanics
- **Виживання:** управління запасами O₂ у споровій зоні
- **Оборона:** захист обладнання від агресивної флори
- **Ремонт купола:** відновлення захисних секцій
- **Збір зразків:** біологічні зразки для аналізу (обережно!)
- **Таймер:** деякі завдання мають часові обмеження
- **Хвилі загроз:** періодичні «цвітіння» спор або росту рослин

### Primary Goal
- Зібрати біологічні зразки та відремонтувати купол для безпечного дослідження

### Reward
- Біологічні дані про екосистему планети
- Knowledge item: роль біоаерозолів у атмосфері (зв'язок з кольором неба)
- Можливо: біо-компонент для стабілізації сигналу

---

## Signal Connection

Біологічні дослідження в Колисці можуть пояснити, чому **біоаерозолі впливають на сигнал** з Візитки. Спори та органічні пігменти в атмосфері можуть створювати перешкоди для електромагнітного випромінювання, що частково пояснює деградацію сигналу.
