## Environment Concept

### Terrain
- Високий пагорб з відкритим видом на небо
- Терасні рівні з науковим обладнанням
- Посадковий майданчик на нижній терасі

### Structures
- Головний купол з телескопом / параболічною антеною
- Серверна кімната з терміналами (CRT-стилістика!)
- Лабораторія з голографічними дисплеями
- Житлові модулі (покинуті)

### Atmosphere
- Безпечна, чистіше повітря на висоті
- Нічне небо з подвійними зірками особливо красиве
- Тихо, тільки гул обладнання

## Gameplay — Puzzle / Hacking

### Arcade Mechanics
- **Хакінг терміналів:** міні-ігри на CRT-терміналах для доступу до даних
- **Калібрування обладнання:** налаштування телескопа/антени (пазл з параметрами)
- **Декодування даних:** розшифровка файлів з інопланетного комп'ютера
- **Послідовність дій:** правильний порядок активації систем
- **Логічні пазли:** схеми, патерни, числові послідовності

### Primary Goal
- Активувати обсерваторію та отримати астрономічні дані

### Reward
- Координати інших планет / сигнали з інших систем
- Knowledge item: зоряна карта та наукові дані цивілізації
- Можливо: декодування частини сигналу з Візитки

---

## Signal Connection

Обсерваторія може бути **приймальною станцією** для сигналів з інших планет. Активація її систем може дозволити:
- Декодувати частину скремблованого сигналу
- Виявити інші вузли мережі (на інших планетах)
- Зрозуміти напрямок, куди вказує сигнал з Візитки
