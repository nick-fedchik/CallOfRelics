## Environment Concept

### Terrain
- Плоска промислова зона з металевими платформами
- Відкриті кар'єри з рудними жилами
- Канали з рідкою водою (охолодження?)

### Structures
- Головний цех з плавильними печами (деякі ще активні)
- Склади з матеріалами та напівфабрикатами
- Робочі станції для обробки ресурсів
- Конвеєрні лінії (деякі рухаються)

### Atmosphere
- Безпечна, підвищена температура біля печей
- Пара та іскри від активних механізмів
- Металевий запах (наративний)

## Gameplay — Gathering / Crafting

### Arcade Mechanics
- **Збір ресурсів:** руда, кристали, метали в різних точках локації
- **Крафтинг:** використання робочих станцій для створення предметів
- **Активація печей:** розв'язання міні-пазлів для запуску виробничих ліній
- **Інвентар:** обмежена вага/об'єм — потрібно обирати, що нести
- **Рідкісні ресурси:** в небезпечних зонах (біля активних механізмів)

### Primary Goal
- Зібрати специфічні ресурси та створити потрібний предмет

### Reward
- Ресурси для ремонту корабля або інших квестів
- Knowledge item: технологічний рівень цивілізації
