## Overview

**Маяк** (Lighthouse) — висока башта-маяк на скелястому мисі. Єдина споруда, видима здалеку завдяки пульсуючому світлу на верхівці. Вертикальна локація з елементами платформінгу та лазіння.

## Environment Concept

### Terrain
- Скелястий мис із крутими схилами
- Вузькі тропи та виступи для лазіння
- Посадковий майданчик біля підніжжя

### Structures
- Центральна вежа-маяк (висота ~200 studs)
- Зовнішні платформи та балкони на різних рівнях
- Зруйнована внутрішня драбина — потрібно шукати альтернативні шляхи
- Верхівка з лінзою/відбивачем та пульсуючим світлом

### Atmosphere
- Безпечна, але сильніший вітер на висоті
- Рожево-бордове небо особливо вражаюче з верхівки
- Подвійний захід сонця видно з оглядового майданчика

## Gameplay — Platforming / Climbing

### Arcade Mechanics
- **Вертикальний прогрес:** піднятися від підніжжя до верхівки
- **Платформінг:** стрибки між виступами, балансування на вузьких карнизах
- **Гравітація 1.2g:** стрибки нижчі (×0.85), робить платформінг складнішим
- **Вітер:** на верхніх рівнях можливі пориви, що зміщують гравця
- **Чекпоінти:** проміжні платформи з безпечними зонами

### Primary Goal
- Дістатися до верхівки маяка та активувати/дослідити лінзу

### Reward
- Панорамний вид на всю планету
- Knowledge item: дані про маяк та його зв'язок з мережею сигналів

## Signal Connection

Маяк може бути частиною **мережі передавачів** — ретрансляційна станція для сигналу з Візитки. Лінза на верхівці може підсилювати або перенаправляти електромагнітний сигнал.
