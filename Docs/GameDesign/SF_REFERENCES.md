## Call of Relics: Orbital Silence

**Версія:** 2.0
**Статус:** Active Development

## Призначення документа

Цей документ є навігаційним індексом та загальним оглядом науково-фантастичної літератури, що є джерелом натхнення для сценарію, лору, наративів та атмосфери гри **Call of Relics: Orbital Silence**.

Детальний аналіз кожного автора та твору — у файлах за періодами:

- [SF_REFERENCES-1950-1979.md](SF_REFERENCES-1950-1979.md) — Золота доба та Нова хвиля (30 авторів)
- [SF_REFERENCES-1980-1999.md](SF_REFERENCES-1980-1999.md) — Кіберпанк та Сучасна класика (15 авторів)
- [SF_REFERENCES-2000-2020.md](SF_REFERENCES-2000-2020.md) — Сучасна SF (10 авторів)

## Ключові теми гри та їх літературне коріння

Кожен твір розглядається через призму ключових тем гри:

| Тема гри | Опис | Період-джерело |
|----------|------|----------------|
| Самотність у космосі | Ізольований дослідник далеко від дому | 1950-70s |
| Спадщина зниклих цивілізацій | Руїни, артефакти, покинуті міста | 1950-90s |
| Контакт без прямого діалогу | Сигнали, маяки, незрозумілі форми зв'язку | 1960-2010s |
| Дослідження без гарантій | Ризик, невизначеність, неповні знання | 1950-80s |
| Відповідальність за знання | Знання як цінність і тягар | 1950-90s |
| Електромагнітні сигнали / The Call | Космічні сигнали невідомого походження | 1960-80s |
| Ретро-футуризм / CRT-естетика | Технологічний вигляд інтерфейсів | 1980s |
| Трансценденція цивілізації | Зникнення через еволюцію, а не загибель | 1950-2000s |
| Планети з власною логікою | Кожна локація — окремий світ | 1950-70s |
| Корабель як дім і база | Мобільна одинока база серед чужих зірок | 1980-90s |

## НАРАТИВНА ФОРМУЛА ГРИ

На перетині цих джерел формується наративна формула **Call of Relics**:

> **Соляріс** (незрозумілий контакт) +
> **Пікнік на узбіччі** (артефакти без пояснень) +
> **2001** (прогресія через маяки) +
> **Місто** (порожні руїни з пам'яттю) +
> **Голос Господа** (амбівалентність сигналу) +
> **Нейромант** (ретро-футуристичний інтерфейс) +
> **Фундація** (знання як порятунок) +
> **Задача трьох тіл** (Темний ліс, мовчання космосу) +
> **Дюна** (планета як живий організм)
