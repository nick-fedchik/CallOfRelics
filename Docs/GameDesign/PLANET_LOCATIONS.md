# Планетні Локації — Система Дослідження
**Project:** Call of Relics: Orbital Silence
**Document Type:** Game Design — Planet Locations System

---

## 1. ЗАГАЛЬНИЙ ОПИС

Планетні локації є основними одиницями ігрового контенту. Гра масштабується не за рахунок одного великого світу, а через множину окремих планет і локальних сценаріїв.

### Ключова концепція

> *Кожна локація — це окрема "гра в грі" зі своїми правилами, цілями та ризиками.*

### Ієрархія ігрового світу

```mermaid
flowchart TB
    subgraph Universe["🌌 Ігровий Всесвіт"]
        subgraph Planet1["🌍 Планета 1"]
            P1_Orbit[🛸 Орбіта]
            P1_L1[📍 Локація 1]
            P1_L2[📍 Локація 2]
            P1_L3[📍 ...]
        end

        subgraph Planet2["🌍 Планета 2"]
            P2_Orbit[🛸 Орбіта]
            P2_L1[📍 Локація 1]
        end

        subgraph Earth["🌍 Земля"]
            E_Orbit[🛸 Орбіта]
            E_Final[🏠 Фінал]
        end
    end

    P1_Orbit --> P1_L1
    P1_Orbit --> P1_L2
    P1_Orbit --> P1_L3
    P2_Orbit --> P2_L1
    E_Orbit --> E_Final

    Planet1 -.->|Warp| Planet2
    Planet2 -.->|Warp| Earth
```

## 2. ПЛАНЕТА ЯК ІГРОВА ОДИНИЦЯ

Планета:
- є тематичним контейнером
- має власну атмосферу, гравітацію та візуальний стиль
- містить кілька планетних локацій
- випромінює один або кілька аномальних сигналів

Планета **не є** ігровою локацією у класичному сенсі. Гравець **ніколи не пересувається по всій планеті** безпосередньо.

### Взаємодія з планетою

```mermaid
flowchart LR
    subgraph Interaction["Способи взаємодії"]
        Orbit[🛸 Орбітальне перебування]
        Scan[🔍 Сканування поверхні]
        Land[🛬 Посадка на локацію]
    end

    Orbit --> Scan
    Scan --> Land
    Land --> Orbit
```

| Спосіб | Опис |
|--------|------|
| Орбіта | Стратегічне планування, безпечна зона |
| Сканування | Виявлення нових локацій |
| Посадка | Фізичне дослідження |

## 3. СТРУКТУРА ПЛАНЕТНОЇ ЛОКАЦІЇ

Кожна планетна локація:
- є ізольованою ділянкою поверхні планети
- доступна лише шляхом посадки корабля
- має власний сценарій, правила та цілі
- є самостійною аркадною грою

```mermaid
flowchart LR
    subgraph Location["📍 Планетна локація"]
        subgraph Landing["🛬 Landing Zone"]
            Ship[🚀 Корабель]
            Spawn[👤 Точка спавну]
            Return[🔙 Точка повернення]
        end

        subgraph Exploration["⚠️ Exploration Zone"]
            Area1[🔍 Зона дослідження]
            Area2[💀 Зона ризику]
            Area3[👾 Зона NPC/аномалій]
        end
    end

    Landing --> Exploration
    Exploration --> Landing
```

### Landing Zone (Безпечна зона)

| Елемент | Опис |
|---------|------|
| Корабель | Місце посадки, точка збереження |
| Точка спавну | Місце появи гравця |
| Точка повернення | Зона для повернення на корабель |

### Exploration Zone (Зона дослідження)

| Елемент | Опис |
|---------|------|
| Зона дослідження | Основна ігрова територія |
| Зона ризику | Активні загрози та небезпеки |
| Зона NPC/аномалій | Спеціальні об'єкти та істоти |

## 4. ЛОКАЦІЯ ЯК АРКАДНА ГРА

Кожна планетна локація — це **"гра в грі"**:
- має чіткий початок (посадка)
- має власні правила
- має головну ціль
- може мати кілька опційних цілей
- має чіткий або умовний фінал

### Activity Diagram: Дослідження локації

```mermaid
flowchart TD
    Start([🚀 Посадка на локацію]) --> Spawn[Спавн у Landing Zone]
    Spawn --> Decision1{Вийти з корабля?}

    Decision1 -->|Ні| StayShip[Залишитись на кораблі]
    StayShip --> Decision1

    Decision1 -->|Так| ExploreZone[Дослідження Exploration Zone]

    ExploreZone --> Actions{Дії гравця}

    Actions -->|Пошук| Search[Пошук об'єктів/артефактів]
    Actions -->|Взаємодія| Interact[Взаємодія з механізмами]
    Actions -->|Збір| Collect[Збір ресурсів]
    Actions -->|Аналіз| Analyze[Спостереження та аналіз]

    Search --> CheckGoal{Головна ціль досягнута?}
    Interact --> CheckGoal
    Collect --> CheckGoal
    Analyze --> CheckGoal

    CheckGoal -->|Ні| Danger{Небезпека?}
    Danger -->|Ні| ExploreZone
    Danger -->|Так| EscapeDecision{Втікати?}

    EscapeDecision -->|Ні| Risk[Ризикувати далі]
    Risk --> Actions

    EscapeDecision -->|Так| Escape[Втеча до Landing Zone]
    Escape --> PartialLoss[Часткова втрата ресурсів]
    PartialLoss --> Return[Повернення на корабель]

    CheckGoal -->|Так| Success[✅ Успішне дослідження]
    Success --> Knowledge[Отримання знань]
    Knowledge --> Resources[Збереження ресурсів]
    Resources --> Return

    Danger -->|Смерть| Death[💀 Ігрова смерть]
    Death --> LossResources[Втрата ресурсів]
    LossResources --> KeepKnowledge[Знання збережено]
    KeepKnowledge --> RespawnShip[Респавн на кораблі]

    Return --> Liftoff([🚀 Зліт на орбіту])
    RespawnShip --> Liftoff
```

### Можливі дії гравця

| Дія | Опис |
|-----|------|
| Дослідження простору | Пересування по локації |
| Пошук об'єктів | Знаходження артефактів |
| Проходження пасток | Уникання небезпек |
| Взаємодія з механізмами | Активація пристроїв |
| Втеча | Екстрене повернення |
| Боротьба | Протистояння з NPC |
| Спостереження | Аналіз явищ |

## 5. СИСТЕМА ЦІЛЕЙ

### Головна ціль

Кожна локація має рівно **одну головну ціль**, яка визначає умову успішного дослідження. Головна ціль фіксується сценарно і не змінюється між візитами.

| Властивість | Опис | Приклад |
|-------------|------|---------|
| Обов'язковість | Потрібна для прогресу | Активувати маяк-передавач |
| Визначення | Фіксується сценарно | Дешифрувати запис зниклої раси |
| Завершення | Визначає перехід у стан Explored | Зібрати 3 фрагменти артефакту |
| Унікальність | 1 на локацію | Дістатися центру аномалії |

### Опційні цілі

Опційні цілі дають додаткову винагороду і можуть змінюватися при повторних візитах. Гравець бачить їх лише після початку дослідження.

| Властивість | Опис | Приклад |
|-------------|------|---------|
| Обов'язковість | Не обов'язкові | Знайти прихований архів |
| Кількість | 2-5 на локацію | 3 опційні цілі на Location_1 |
| Зміна | Можуть оновлюватися між візитами | Нова ціль після вивчення лору |
| Винагорода | Додаткові ресурси або знання | +50 knowledge, +20 resources |

### Порівняння типів цілей

| Характеристика | Головна ціль | Опційна ціль |
|----------------|-------------|-------------|
| Кількість на локацію | 1 | 2-5 |
| Обов'язковість | Так | Ні |
| Вплив на стан локації | Переводить у Explored | Ні |
| Видимість | Від початку візиту | Після початку дослідження |
| Зміна при повторних візитах | Ні | Можлива |
| Втрата при смерті | Не зараховується | Знання збережено |

```mermaid
pie title Співвідношення головних та опційних цілей
    "Головна ціль (1 на локацію)" : 1
    "Опційні цілі (2-5 на локацію)" : 3
```

## 6. КЛАСИФІКАЦІЯ ЛОКАЦІЙ (12 типів)

Для уніфікації дизайну використовується система типів локацій. Кожна локація має:
- **Primary Type** — основний тип
- **Secondary Type** (опціонально) — другорядний тип

### Зведена таблиця типів локацій

| # | Тип | Фокус | Практичний опис | Ключові механіки |
|---|-----|-------|----------------|------------------|
| 1 | **Story** | Наратив та лор | Локація побудована навколо розповіді. Гравець досліджує середовище, що розказує історію через записи, голограми, написи на стінах, залишки побуту зниклої цивілізації. Ризик мінімальний — основна цінність у контексті та знаннях. Підходить для початку гри та ключових сюжетних поворотів. | Читання написів, прослуховування записів, огляд артефактів, діалоги з ШІ-фрагментами, environmental storytelling |
| 2 | **Exploration** | Дослідження простору | Відкрита територія для вільного дослідження. Гравець обирає напрямок руху, відкриває точки інтересу, картографує невідомий терен, збирає базові ресурси. Низький ризик, але потребує уваги до орієнтування. Нагороджує допитливість і системність. | Вільне переміщення, розвідка, відкриття POI, картографування, збір ресурсів, орієнтування на місцевості |
| 3 | **Puzzle** | Логічні задачі | Локація з головоломками та механізмами, що потребують розв'язання. Гравець аналізує інопланетні пристрої, шукає підказки в середовищі, комбінує елементи для активації порталів чи систем. Ризик залежить від типу загадки — деякі мають обмеження часу або невдалі спроби. | Логічні послідовності, дешифрування символів, маніпуляції з механізмами, комбінування елементів, просторові задачі |
| 4 | **Survival** | Виживання | Ворожі умови середовища створюють постійний тиск. Гравець управляє кисневим запасом, укривається від стихій, планує маршрут між безпечними точками. Таймери та обмежені ресурси примушують до швидких рішень. Високий ризик — нагорода відповідна. | Управління кисневим запасом, таймери, пошук укриттів, планування маршруту, стихійні загрози, деградація обладнання |
| 5 | **Combat** | Бойове протистояння | Активне зіткнення з ворожими NPC, істотами або автоматичними системами захисту. Гравець використовує тактику, позиціонування та доступне спорядження. Найвищий ризик із найвищою винагородою. Підходить для досвідчених гравців. | Тактичне позиціонування, використання укриттів, вибір спорядження, аналіз патернів ворогів, управління здоров'ям |
| 6 | **Hybrid** | Комбінація 2-3 типів | Складна локація, що динамічно змінює тип геймплею. Починається як exploration, переходить у puzzle при знахідці, може ескалюватися в combat або survival. Вимагає адаптивності — гравець не знає заздалегідь, що на нього чекає. | Зміна типу геймплею за тригерами, варіативні маршрути, адаптація стратегії, непередбачуваність, багатошарова структура |
| 7 | **Stealth** | Приховане пересування | Гравець повинен пересуватися непоміченим через зону з активними патрулями, сенсорами або сплячими загрозами. Виявлення має серйозні наслідки — від бою до миттєвої невдачі. Темп повільний, напруга висока. | Вивчення маршрутів патрулів, тайминг переміщень, уникання сенсорів, шумова механіка, зони видимості |
| 8 | **Escape** | Втеча під тиском | Локація починається як дослідження, але після тригеру (активація артефакту, руйнування структури) перетворюється на гонку за виживання. Зворотний відлік, руйнування середовища, зростаюча загроза. Перевіряє швидкість рішень і знання маршрутів. | Зворотний відлік, руйнування середовища, динамічні перешкоди, пошук найкоротшого шляху, прийняття рішень під тиском |
| 9 | **Resource** | Збір цінних ресурсів | Локація з високою концентрацією ресурсів, але кожен ресурс захищений загрозою — радіація, хижаки, нестабільність. Гравець зважує ризик і вигоду: більше зібрав — більше ризикував. Стимулює жадібність як ігрову механіку. | Видобуток ресурсів, управління ризиком, обмежений час збору, ворожі охоронці, рішення «скільки ще збирати» |
| 10 | **Anomaly** | Незрозумілі явища | Фізичні закони працюють інакше: простір нелінійний, час тече нерівномірно, об'єкти ведуть себе незвично. Правила локації треба відкрити експериментуванням. Висока інтелектуальна складність — нагорода пропорційна. | Експериментування з середовищем, порушення фізичних законів, нелінійний простір, непередбачувані ефекти, індуктивне мислення |
| 11 | **Observation** | Пасивне дослідження | Локація для спостереження та аналізу. Гравець фіксує патерни поведінки екосистем, інтерпретує сигнали, документує явища. Мінімальне фізичне втручання — максимальна аналітична робота. Нагороджує терпіння та уважність. | Фіксація патернів, аналіз даних, інтерпретація сигналів, пасивне спостереження, кореляція подій, запис у базу знань |
| 12 | **Trial** | Перевірка навичок | Спеціально сконструйоване випробування, створене давньою расою для оцінки розуму прибульців. Серія зростаючих за складністю завдань, що перевіряють кмітливість, етику, знання та здатність до адаптації. Фінальний іспит перед отриманням ключових знань. | Послідовність зростаючих випробувань, тестування різних навичок, моральні дилеми, оцінка знань, адаптивна складність |

## 7. СТАНИ ПЛАНЕТНОЇ ЛОКАЦІЇ

Кожна планетна локація має такі логічні стани:

```mermaid
stateDiagram-v2
    [*] --> Unknown: Початковий стан

    Unknown --> Discovered: Сканування з орбіти
    Discovered --> Visited: Посадка на локацію
    Visited --> Explored: Досягнення головної цілі

    note right of Unknown
        Не виявлена
        Не видима на карті
    end note

    note right of Discovered
        isDiscovered = true
        Доступна для посадки
    end note

    note right of Visited
        isVisited = true
        Гравець був на локації
    end note

    note right of Explored
        Головна ціль виконана
        Прогрес зараховано
    end note
```

### Таблиця станів

| Стан | Прапор | Опис |
|------|--------|------|
| **Unknown** | — | Локація не знайдена, не видима |
| **Discovered** | `isDiscovered = true` | Знайдена з орбіти, доступна для посадки |
| **Visited** | `isVisited = true` | Гравець фізично відвідав локацію |
| **Explored** | Головна ціль виконана | Прогрес зараховано |

### Persistence

Всі стани локацій зберігаються між ігровими сесіями у профілі гравця.

## 8. КРИТЕРІЇ ДОСЛІДЖЕННЯ

### Мінімальний критерій

Локація вважається дослідженою, якщо гравець **досяг головної цілі локації**.

**Недостатньо:**
- ❌ Сканування
- ❌ Дистанційний аналіз
- ❌ Інформація з орбіти

**Необхідно:**
- ✅ Фізична присутність
- ✅ Взаємодія з середовищем
- ✅ Досягнення головної цілі

### Фізична присутність

> Локація не вважається дослідженою, поки гравець фізично не перебував у її межах та не досяг головної цілі.

## 9. РЕСУРСИ ЛОКАЦІЇ

### Два типи винагород

| Тип | Збереження | При смерті | При втечі | Приклад |
|-----|-----------|------------|-----------|---------|
| **Knowledge** | Назавжди | 100% збережено | 100% збережено | Лор, записи, дешифровані дані, карти |
| **Resources** | До втрати | 0% | ~50% | Мінерали, енергоклітини, артефакти |

> **Ключовий принцип:** Знання ніколи не втрачаються. Ресурси — ставка гравця.

### Правила розподілу ресурсів

| Візит | Кількість ресурсів | Knowledge | Примітка |
|-------|-------------------|-----------|----------|
| Перший | 100% | Повний доступ | Максимальна нагорода |
| Повторний | 30-50% | Нові опційні знання | Часткове відновлення |
| Унікальні предмети | Одноразово | Одноразово | Тільки при першому успішному візиті |

### Стимулювання

Система ресурсів стимулює:

- Уважне первинне дослідження — перший візит завжди найвигідніший
- Зважене рішення про повторні візити — ресурсів менше, але нові знання можливі
- Пріоритезацію нових локацій — невідомі локації завжди цінніші за вже відвідані
- Ризик-менеджмент — зібрати більше = ризикувати довше

## 10. ПОВТОРНЕ ВІДВІДУВАННЯ

При повторному відвідуванні:

| Аспект | Зміна |
|--------|-------|
| Головна ціль | Вже виконана |
| Ресурси | Зменшені або відсутні |
| Опційні цілі | Можуть бути іншими |
| Контекст | Може відкривати новий |

Повторні візити **не є обов'язковими**, але заохочуються для:
- Нових опційних цілей
- Додаткового контексту
- Залишкових ресурсів

## 11. НЕВДАЛІ СТАНИ ТА НАСЛІДКИ

Гра допускає невдале завершення дослідження локації. Невдача не означає кінець гри, але має відчутні наслідки.

```mermaid
flowchart TB
    subgraph Location["📍 На локації"]
        Explore[Дослідження]
        Goal[Головна ціль]
    end

    subgraph Outcomes["Результати"]
        Success[✅ Успіх]
        Escape[🏃 Втеча]
        Death[💀 Смерть]
    end

    subgraph Consequences["Наслідки"]
        SuccessR[Прогрес + Ресурси + Знання]
        EscapeR[Часткові ресурси втрачено<br/>Знання збережено]
        DeathR[Ресурси втрачено<br/>Знання збережено]
    end

    Explore --> Goal --> Success --> SuccessR
    Explore --> Escape --> EscapeR
    Explore --> Death --> DeathR

    EscapeR --> Ship[🚀 Корабель на орбіті]
    DeathR --> Ship
    SuccessR --> Ship
```

### 11.1. Втеча з локації

| Аспект | Наслідок |
|--------|----------|
| Головна ціль | Не виконана |
| Статус локації | Не досліджена |
| Ресурси | Частково втрачені |
| Знання | Збережені |

Втеча є **допустимим рішенням** і частиною геймплейної стратегії.

### 11.2. Ігрова смерть

**Причини:**
- Небезпечні умови
- Пастки
- NPC або істоти
- Сценарні події

**Наслідки:**

| Аспект | Наслідок |
|--------|----------|
| Ресурси | Втрачені |
| Головна ціль | Не зарахована |
| Знання | **Збережені** |
| Респавн | Корабель на орбіті |

### 11.3. Філософія невдачі

> *Невдача є частиною дослідження, а не покаранням.*

Невдача у грі:
- Не карає гравця повним відкатом
- Зберігає отримані знання
- Заохочує повторні спроби з новим підходом

## 13. ПРОГРЕСІЯ ДОСЛІДЖЕННЯ

Типова послідовність дослідження планети включає цикли «орбіта → сканування → посадка → дослідження → повернення». Кожна ітерація відкриває нові локації та поглиблює розуміння планети.

### Gantt: Типовий шлях дослідження планети

```mermaid
gantt
    title Прогресія дослідження планети
    dateFormat X
    axisFormat %s

    section Орбіта
    Прибуття на орбіту       :a1, 0, 5
    Перше сканування         :a2, after a1, 3

    section Локація 1 (Story)
    Посадка                  :b1, after a2, 2
    Дослідження              :b2, after b1, 10
    Повернення               :b3, after b2, 2

    section Розвиток
    Друге сканування         :c1, after b3, 3

    section Локація 2 (Exploration)
    Посадка                  :d1, after c1, 2
    Дослідження              :d2, after d1, 15
    Повернення               :d3, after d2, 2

    section Завершення
    Підготовка до warp       :e1, after d3, 5
```
